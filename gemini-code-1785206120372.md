# Implementation Plan: Piece-Rate Payroll Module (Phase 2)

## 1. Overview & Business Logic
Modul Penggajian Borongan (Piece-Rate Payroll System) untuk pabrik jahit / konveksi Toko Seragam Oliviana. 

### Core Logic:
1. **Multi-Role Access**: Penambahan role `WORKER` (Pekerja/Penjahit).
2. **Master Tarif Borongan**: Setting harga per item pekerjaan untuk setiap jenis pakaian (tanpa membedakan ukuran).
3. **Daily Worker Entry (Harian)**: Pekerja melaporkan hasil pengerjaan komponen baju harian via HP/Mobile View. Multi-item input dalam sekali submit.
4. **Monthly Accumulation & Approval (Bulanan)**: Laporan harian terakumulasi selama 1 bulan. Owner melakukan verifikasi & pencairan gaji di akhir bulan.
5. **Cash Auto-Deduction & Transaction History**: Saat gaji bulanan di-approve, saldo kas toko otomatis terpotong & riwayat pengeluaran kas ter-record.
6. **Simple Slip Gaji**: Cetak/Download Slip Gaji Bulanan (Format Thermal 80mm / A5 / PDF / WA Share).

## 2. Database Schema Extensions (PostgreSQL / Supabase)

```sql
-- 1. Update Role Constraint in Users Table
ALTER TABLE users DROP CONSTRAINT IF EXISTS users_role_check;
ALTER TABLE users ADD CONSTRAINT users_role_check CHECK (role IN ('OWNER', 'CASHIER', 'WORKER'));

-- 2. Master Work Rates (Item Pekerjaan & Tarif per Jenis Pakaian)
CREATE TABLE piece_rate_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    product_id UUID REFERENCES products(id) ON DELETE CASCADE, -- Jenis Pakaian (e.g., Rok Panggul, Celana Levis)
    item_name VARCHAR(150) NOT NULL, -- e.g., "Ngobras nyambung", "Masang resleting", "Nata kain"
    rate_price DECIMAL(12,2) NOT NULL, -- Tarif Rupiah per Pcs
    created_at TIMESTAMP DEFAULT NOW()
);

-- 3. Daily Worker Log Header
CREATE TABLE worker_daily_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    worker_id UUID REFERENCES users(id) ON DELETE CASCADE,
    log_date DATE NOT NULL DEFAULT CURRENT_DATE,
    total_daily_amount DECIMAL(12,2) DEFAULT 0,
    status VARCHAR(20) DEFAULT 'PENDING' CHECK (status IN ('PENDING', 'APPROVED', 'PAID')),
    created_at TIMESTAMP DEFAULT NOW()
);

-- 4. Daily Worker Log Details (Multi-item entry per day)
CREATE TABLE worker_daily_log_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    daily_log_id UUID REFERENCES worker_daily_logs(id) ON DELETE CASCADE,
    piece_rate_item_id UUID REFERENCES piece_rate_items(id),
    quantity INT NOT NULL,
    rate_per_unit DECIMAL(12,2) NOT NULL,
    subtotal DECIMAL(12,2) NOT NULL
);

-- 5. Monthly Payroll Summary (Pencairan Gaji Bulanan)
CREATE TABLE payroll_disbursements (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    payroll_number VARCHAR(50) UNIQUE NOT NULL, -- e.g., "PAY-202607-001"
    worker_id UUID REFERENCES users(id),
    month_year VARCHAR(7) NOT NULL, -- Format: "YYYY-MM" (e.g., "2026-07")
    total_amount DECIMAL(12,2) NOT NULL,
    approved_by UUID REFERENCES users(id),
    paid_at TIMESTAMP DEFAULT NOW()
);

-- 6. Cash Flow Expense Logging (Keuangan Toko)
CREATE TABLE cash_expenses (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    expense_category VARCHAR(50) DEFAULT 'PAYROLL',
    amount DECIMAL(12,2) NOT NULL,
    description TEXT NOT NULL,
    reference_id UUID, -- References payroll_disbursements.id
    created_by UUID REFERENCES users(id),
    created_at TIMESTAMP DEFAULT NOW()
);
